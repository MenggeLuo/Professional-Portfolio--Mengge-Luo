## Introduction

This project is a responsive personal portfolio website that highlights my professional background, skills, work experience, and projects. It is designed to give an overview of my qualifications in the field of software development.

The website is built using HTML5, CSS3, and JavaScript, and is hosted via GitHub Pages.

## Technologies Used

- **HTML5**: For the structure and layout of the content.
- **CSS3**: To style the website and ensure it's responsive on different devices.
- **JavaScript**: For interactive elements.
- **GitHub Pages**: Hosting platform for the website.

## Features

- Responsive design that adapts to different devices (desktop, tablet, and mobile).
- Project showcase with links to the GitHub repositories.
- Interactive elements like hover effects on project images.
- Contact information with mailto and tel links for easy communication.
- Use toggleButton to adjust different devices.
